# GitHub-аудит компонентов для SONORA

**Проверено:** 25 ноября 2026.  
**Лицензия приложения:** MIT ([`LICENSE`](../LICENSE)).  
**Правило отбора:** сохранить Electron UI + C++/WASAPI ядро, не добавлять зависимости с несовместимой лицензией без отдельного решения. Ссылки ведут на upstream GitHub; исходники, скриншоты и данные SONORA туда не отправлялись. Внешние репозитории в эту рабочую копию не клонировались.

## Что показала сверка с FL Studio

Текущая публичная страница FL Studio описывает больше 100 встроенных инструментов/эффектов/звуков. Из категорий, заметно отстающих в SONORA: полноценный семиполосный EQ и встроенный анализатор, realtime plugin hosting, многополосный микшерный routing, sampler/широкая библиотека, waveform editor, slice/time-stretch/warp, внешний MIDI, аудиозапись acceptance на устройстве, chord/loop tools, stem separation и инструментальные/модуляционные эффекты. Ссылки на подробный список: [официальная страница FL Studio](https://www.image-line.com/fl-studio), [таблица покрытия SONORA](../FL_STUDIO_PARITY_PLAN.md).

## Предлагаемый порядок интеграции

1. **Signalsmith Stretch — короткий локальный spike:** только в disposable test branch/build output. Сравнить с текущим pitch worker на 44.1/48/96 kHz, факторах 0.75/1/1.25/1.5, голосе, ударных и моно/стерео; учитывать algorithm latency и full song offline render. Сначала подтвердить все notices/dependencies; потом решать о встраивании.
2. **Realtime CLAP:** расширять существующий helper/process architecture по reference clap-host; поддержать activate/deactivate, audio thread/block lifecycle, param flush/events, state save/restore, plugin UI strategy, crash timeout, device/graph recreation и bounded scanning. Qt reference UI не переносить.
3. **MIDI аппаратные устройства:** добавить отдельный backend API слой (RtMidi), enumerate/hotplug, note/CC input, MIDI clock/output, устройство исчезает/возвращается, latency/stability. Работать с текущим native host, не заставлять UI обращаться к device handles напрямую.
4. **SoundFont sampler:** C API в изолированной DLL worker/library и банк только с подтверждённой лицензией; не включать чужие soundfont-паки из случайных репозиториев.
5. **VST3:** только после стабильного realtime plugin model и проверки лицензии pinned SDK commit плюс всех submodule/third-party manifests.

Это результаты ресёрча, не утверждение, что компонент установлен или интегрирован. Следующая фактическая интеграция должна закрепить commit hash, копию лицензии/third-party notices, reproducible build, DSP/audio regression coverage и размер/CPU budget.
