# SONORA Studio

Локальная музыкальная студия для Windows 11. Её можно запускать в Edge/Chrome или как отдельное Windows-приложение на Electron. Приложение не требует аккаунта, облака или внешнего API.

## Запуск

1. Установите Node.js 20 или новее.
2. Откройте PowerShell в этой папке.
3. Выполните `npm start`.
4. Откройте `http://127.0.0.1:4173` в Edge или Chrome.
5. Для режима отдельного окна в Edge откройте меню `… → Приложения → Установить этот сайт как приложение`.

В настольном приложении ⚙ показывает устройства WASAPI и тестовый сигнал. Совместимые проекты с аудиоклипами, MIDI/ударными и встроенными реверберацией/задержкой воспроизводятся через WASAPI; MIDI и ударные перед запуском рендерятся в PCM-клипы. Метроном пока использует Web Audio. Нативная реверберация — лёгкая алгоритмическая комнатная модель, не идентичная браузерному convolution reverb. Smoke открывает реальный WASAPI output, но передаёт цифровую тишину и не подтверждает слышимое воспроизведение. Проверки движка: `npm run native:test`, `npm run native:smoke`; синтетический микробенчмарк: `npm run native:bench`.

В настольной версии запись использует выбранный WASAPI-вход, если он доступен; в браузере применяется Web Audio. Через ⚙ выберите устройство, частоту 44,1/48/96 кГц, канал и целевую дорожку. Запись формируется в фоновом файловом потоке с ограничением 256 МиБ и после остановки добавляется в Arrangement и вкладку «Мои записи». На текущем компьютере WASAPI-вход не найден, поэтому нативная запись проверена синтетическими данными и unit-тестами, но ещё не проверена с физическим микрофоном.

Громкость дорожки можно автоматизировать клипом с редактируемыми линейными точками. Кривые работают в Web Audio, WAV-рендере и нативном WASAPI track mixer; клипы преобразуются в sample-frame events и интерполируются заранее на блок, без выделения памяти в аудиоколбэке. Перекрывающийся более поздний клип перехватывает управление. Панорама, эффекты и параметры плагинов пока не автоматизируются. Подробный перечень сценариев, сопоставленных с FL Studio, и открытых функций — в [плане совместимости](FL_STUDIO_PARITY_PLAN.md).

В настольных свойствах аудиоклипа можно выбрать CLAP `.clap` эффект, изменить его параметры и выполнить offline-рендер. Поддерживаются доступные для управления CLAP-параметры стереоэффекта; изменение значений применяется при новом рендере. Плагин запускается в отдельном вспомогательном процессе с лимитом 120 секунд, поэтому сбой плагина не завершает Electron или WASAPI callback. Это изоляция процесса для устойчивости, а не граница безопасности: выбранный плагин работает с правами пользователя. Исходный клип и значения параметров сохраняются в `.sonora`; для повторного рендера после перезапуска нужно выбрать плагин ещё раз. CLAP-инструменты, многоканальные схемы и VST3 пока не поддерживаются.

Текущая сборка остаётся ранним прототипом, а проект ещё не прошёл проверку на Windows 11. Архитектура, IPC и лицензии зафиксированы в [ADR-0001](docs/architecture/ADR-0001-native-audio-engine.md); детали нативного микшера и его ограничения — в [описании аудиодвижка](native/README.md).

## Проверки

`npm test` запускает проверки Arrangement, DSP, Electron preload bridge, AudioWorklet, защиты локального сервера и CLAP-renderer. `npm run native:clap:test` собирает тестовый stereo gain-плагин и проверяет CLAP render, WAV-выход, хвост и отказ для неверного бинарного файла. `npm run native:test` запускает 18 тестов C++ ядра, включая интерполяцию автоматизации между блоками/seek и отклонение некорректных кривых. `npm run native:smoke` проверяет протокол set_track automation и WASAPI transport на цифровой тишине, освобождение неиспользуемых аудиоданных, обновления проекта и native memory diagnostics. Нативный кэш ограничивает один декодированный asset 256 МиБ и временный объём 1 ГиБ.

Для целевых QA-проходов доступны `npm run qa:quick`, `npm run qa:audio`, `npm run qa:plugin`, `npm run qa:load`, `npm run qa:stability` и `npm run qa:final`. `qa:load` измеряет только нативный микшер, `qa:stability` выполняет двухминутный беззвучный WASAPI soak с memory sampling, а `qa:final` запускает полный Windows release gate. Визуальная проверка сейчас выполняется подключённым Playwright MCP; отдельный Playwright test-runner в зависимости проекта не установлен. Реестр и отчёты: `UI_INVENTORY.json`, `TEST_COVERAGE_MATRIX.md`, `QA_MASTER_PLAN.md`, [FL Studio parity plan](FL_STUDIO_PARITY_PLAN.md) и связанные `*_REPORT.md`.

## Что работает

- русскоязычный экран проекта: Browser, Arrangement, транспорт и микшер;
- браузерная библиотека содержит вкладку «Проект» для импортированных/обработанных звуков, клавиатурный выбор и запуск предпрослушивания; карточка показывает реальную PCM-волну, длительность, частоту дискретизации, каналы и объём Float32-буфера в памяти;
- генеративные локальные drum-сэмплы без внешних аудиофайлов, предпрослушивание и перетаскивание на шкалу;
- импорт WAV/MP3/OGG/M4A/FLAC, видимая форма волны и одновременное воспроизведение клипов;
- перемещение и обрезка клипов, разделение у курсора, дублирование, удаление, маркеры частей;
- выделение цикла перетаскиванием линейки или кнопками A/B, цикл по выбранному диапазону, сохранение диапазона в `.sonora` и Undo/Redo;
- пошаговый ритм и простая MIDI-партия для встроенных осцилляторных тембров;
- встроенный инструментальный инспектор: выбор тембра и формы волны, срез low-pass фильтра, атака, затухание и расстройка; параметры применяются в предпрослушивании, браузерном и WASAPI воспроизведении, а также при экспорте. Браузер включает четыре встроенных пресета, применяющих настоящие настройки синтезатора;
- неразрушающий pitch shift на ±24 полутона с сохранением длины клипа (WSOLA-обработка выполняется в отдельном worker), а также независимая регулировка скорости клипа;
- базовая коррекция монофонического голоса к мажорной или минорной тональности проекта с настройками силы и скорости, сравнением обработанного звука с оригиналом;
- offline-рендер выбранного участка аудиоклипа сторонним стерео CLAP эффектом с редактированием параметров в инспекторе клипа;
- запись выбранного входа в моно или стерео с выбором канала и целевой аудиодорожки через AudioWorklet; доступны частоты 44,1/48/96 кГц для браузерного аудио; также есть индикация входа, регулировка громкости и панорамы клипа/дорожки, простые эффекты реверберации и задержки;
- сохранение проекта в переносимый `.sonora` с включённым аудио, открытие проекта и экспорт WAV с трёхсекундным хвостом встроенных эффектов;
- безопасная загрузка `.sonora`: проверяются PCM16 WAV-заголовки и ссылки на аудио; ограничения редактора соответствуют лимитам формата — 128 дорожек, 512 аудиофайлов, 8192 клипа, 65 536 MIDI/ритм-событий, 320 МиБ декодированного аудио и размер файла не более 256 МиБ;
- Undo/Redo для основных правок, масштаб Arrangement и горячие клавиши: Space, Delete, Ctrl+S, Ctrl+O, Ctrl+D.
- четыре локальные цветовые темы интерфейса (Dark Rose, Bordeaux, Aqua Graphite, Neon Rose) с применением без остановки воспроизведения; новые дорожки используют палитру выбранной темы, заданные в проекте цвета сохраняются.
- контекстный инспектор дорожки справа: выбор дорожки, переименование, цвет, громкость, панорама, mute/solo и встроенные эффекты; инспектор клипа показывает тип, позицию и длительность. На узком окне он открывается поверх рабочей области и закрывается кнопкой или фоном.

## Цветовая тема

Откройте ⚙ → «Тема интерфейса». Выбор применяется немедленно и сохраняется локально в браузере/Electron-профиле. Неизвестное или повреждённое значение возвращает Dark Rose. Темы меняют оформление интерфейса и палитры новых дорожек/паттернов, не меняя сохранённые цвета проекта.

## Известные ограничения

Это ранний самостоятельный прототип, а не замена зрелой DAW. Аудиоклипы идут через нативный WASAPI-микшер; MIDI и ударные синтезируются в PCM перед WASAPI воспроизведением, а при недоступности движка используют Web Audio. Встроенный синтезатор предлагает базовые настройки осциллятора и огибающей; это не полноценный полифонический инструмент уровня Serum. Нативный путь поддерживает clip/track gain-pan, mute/solo, playback rate, встроенные reverb/delay и offline-обработку stereo CLAP эффектами с редактируемыми параметрами. CLAP GUI, CLAP-инструменты, MIDI-устройства и параметрический эквалайзер не подключены. WASAPI-запись реализована, но на этом хосте нет доступного входного устройства. Pitch shift и автотюн проверены на синтетических тонах; качество на реальном вокале ещё требует оценки. Цифровой smoke-тест и отдельная opt-in проверка передачи 440 Гц PCM в WASAPI callback пройдены; физическую слышимость программно проверить нельзя. Чистая установка и реальный вывод на Windows 11 ещё не проверены.

## Ресурсы компьютера

Native-кэш пока хранит уникальные источники полностью в 48 кГц, stereo, float32: примерно **22 МиБ на минуту** аудио. Например, 10 минут уникального материала занимают около 220 МиБ только в native-кэше; отдельно остаются буферы браузера и временный WAV при подготовке. Кэш ограничен 1 ГиБ; при превышении нативный путь отклонит проект и приложение продолжит через Web Audio, если хватает памяти браузера. Потоковое чтение больших клипов и полные замеры RAM приложения не сделаны, поэтому это расчёт памяти PCM, а не минимальная системная спецификация.

Локальный микробенчмарк нативного микшера на AMD Ryzen 9 3900X и 32 ГиБ RAM измерял 3000 блоков по 512 кадров (10,67 мс каждый), с 4 разными PCM-источниками и без вывода на устройство. Для 1/8/32/64/128 одновременно активных клипов p95 времени микширования составил примерно **3,4/26,5/107,9/214,4/427 мкс**. Отдельный сценарий с 8 дорожками, где включены оба эффекта, занял p95 около **104 мкс**. Это измерение только C++ микшера на текущем компьютере под Windows 10; оно не измеряет Electron, WASAPI underruns или Windows 11 и не является официальным минимумом.

## Основа и лицензии

Первая версия сделана независимо на Web Audio API, Web Audio Offline Rendering и браузерном микрофонном API. Код Vibez, Zrythm, LMMS, Ardour, SampleForge и музыкальные звуковые наборы в приложение не копировались. Примеры ударных синтезируются кодом на лету, внешние звуки не поставляются.

Код приложения распространяется по MIT (см. `LICENSE`). Нативный движок включает miniaudio 0.11.26 (MIT No Attribution), а offline-хост эффектов использует официальные заголовки CLAP 1.2.3 (MIT); уведомления обеих лицензий включены в установщик. Плагины выбираются локально и не входят в продукт.

Репозитории из исходного задания использованы для сравнения возможностей и лицензий:

- [Vibez](https://github.com/alexanderwanyoike/vibez) — GPL-3.0-or-later; проект сообщает о Windows-сборках в CI и всё ещё описывает себя как alpha. Код не заимствован.
- [Zrythm](https://github.com/zrythm/zrythm) — крупная native DAW на C++/Qt/JUCE с инструкциями сборки для Windows x64. В README текущей версии отдельно перечислены функции v1, ещё не перенесённые в v2. Код не заимствован; лицензии проекта и зависимостей требуют отдельного учёта.
- [LMMS](https://github.com/LMMS/lmms) — GPL-2.0, полезен как ориентир по Piano Roll/Step Sequencer; [репозиторий ассетов LMMS](https://github.com/LMMS/assets) отдельно лицензирует содержимое как CC0. Код и ассеты не включены.
- [Ardour](https://github.com/Ardour/ardour) — крупная C/C++ система для технического сравнения записи и аудиодвижка; код не включён.
- [LogicalArdour](https://github.com/jmantra/LogicalArdour) — репозиторий с MIT-лицензией, но его README перечисляет многие пункты как цели проекта; трактовать их как готовые возможности было бы неверно. Он не использован.
- [Signalsmith Stretch](https://github.com/Signalsmith-Audio/signalsmith-stretch) — C++ библиотека pitch/time с MIT-лицензией; для этого браузерного прототипа пока не подключалась.
- [SnapTune](https://github.com/NicoFerni/snaptune) — AGPL-3.0, отдельный Windows VST3 доступен, но это не встроенный движок и не может работать в текущем браузерном приложении без VST-хоста. Код не подключён.
- [Skatotune](https://github.com/sdunifon/skatotune) — Windows/Linux сборки указаны как планируемые и не проверенные авторами; не использован.
- [SampleForge](https://github.com/tpj67/sampleforge) — небольшой браузерный пример, но в репозитории не обнаружена явная лицензия; код и WASM не заимствованы.
- [Каталог инструментов](https://github.com/MiniDraco/musical-instruments-master-list) — CC BY-SA 4.0; используется только как справочный кандидат, его данные не включены.

В проекте нет импортированного кода перечисленных DAW и нет скопированных аудиоматериалов. Electron обеспечивает отдельное Windows-окно, Web Audio — интерфейсную совместимость, C++/miniaudio — WASAPI-путь для аудиопроектов, а отдельный CLAP helper — offline-обработку стерео эффектами. Это независимая реализация, а не форк Vibez/Zrythm/LMMS. VST3 и ASIO пока не подключены.
